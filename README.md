# Windows Active Directory Home Lab

## Overview

This project demonstrates a hands-on Windows Active Directory environment built using Windows Server 2022 and Windows 10 virtual machines.

The lab covers domain controller deployment, Active Directory Domain Services, organizational units, users, security groups, DNS, DHCP, Group Policy, shared folders, permissions, 
client computers, and troubleshooting.

## Skills Demonstrated

- Windows Server 2022 administration
- Active Directory Domain Services
- Domain controller deployment
- Active Directory Users and Computers
- Organizational Units
- User account management
- Security group management
- Group Policy administration
- DNS configuration
- DHCP configuration
- Domain-joined Windows clients
- SMB file sharing
- NTFS permissions
- Network drive mapping
- Access-control troubleshooting
- Windows authentication
- Help desk troubleshooting
- Technical documentation

## Lab Components

### Active Directory
- Created and configured an Active Directory domain
- Created organizational units
- Created users
- Created department and role-based security groups
- Managed user and group membership

### DNS
- Configured DNS services
- Verified forward and reverse lookup functionality
- Tested name resolution from domain clients

### DHCP
- Configured DHCP services
- Created address scope configuration
- Verified automatic IP assignment

### Group Policy
Configured and tested multiple Group Policy Objects, including workstation and user security settings.

### Shared Folders
- Configured Windows file shares
- Configured share permissions
- Configured NTFS permissions
- Tested read/write access
- Mapped network drives to client computers
- Tested access-denied scenarios

### Client Computers
- Joined Windows 10 systems to the domain
- Tested domain authentication
- Verified Group Policy application
- Tested shared-resource access

### Troubleshooting
Performed troubleshooting involving:
- Network connectivity
- DNS
- Domain authentication
- Shared folder permissions
- Network drive mapping
- User access
